# Site görselleri

Tüm görseller `public/images/` altında tutulur. Proje köküne veya `src/` içine ham görsel koymayın.

## Klasör yapısı

| Klasör | İçerik |
|--------|--------|
| `retim/` | Retim marka ve site görselleri (hero, logo, keşif, öncesi/sonrası, hizmetler, projeler) |
| `retim/logo/` | Navbar ve footer logosu (`retim-logo.jpg`) |
| `retim/before-after/` | Termal karşılaştırma görselleri |
| `retim/services/` | Hizmet kartı fotoğrafları (yoksa SVG placeholder) |
| `retim/projects/` | Proje detay fotoğrafları |
| `partners/` | Çözüm ortağı logoları |
| `projects/` | Hizmet/proje SVG placeholder'ları |

Path tanımları: `src/data/mediaAssets.ts`, `src/data/partners.ts`
